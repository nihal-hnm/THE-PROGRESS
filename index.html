Couch Critics

Production

A comprehensive cinema journal and entertainment tracker recording watch journeys, providing smart OTT provider redirection, and organizing personal movie/show catalogs.

Role: Full-Stack Engineer & Creator • Launched: 3/10/2026

Couch Critics — Currently Watching Shelf
Live App UI

Key Engineering Highlights & Architectural Decisions

  • Tripartite Classification & Review Workflow: Engineered an interactive cinema journaling workflow featuring a tripartite classification system ("Watched", "Watching", and "Want to Watch") paired with custom score ratings and personal review logs.
  • TMDB API & Smart OTT Redirection: Integrated TMDB API to dynamically fetch rich streaming metadata, high-resolution poster art, episodic guides, and deep-link redirection to active regional OTT platforms.
  • Supabase Persistence & Row-Level Security: Architected backend persistence using Supabase (PostgreSQL) with Row-Level Security (RLS) policies, session-based authentication, and cloud storage to ensure strict user-partitioned data privacy.
  • Midnight Cinema Aesthetic & State Sync: Constructed a responsive "Midnight Cinema" aesthetic using Next.js 16 App Router and React 19, backed by hybrid state synchronization between local storage and cloud databases.
